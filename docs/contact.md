# Get in contact

NOMAD, `pynxtools`, and `pynxtools-xrm` are open source projects that warmly welcome community projects, contributions, suggestions, bug fixes, and constructive feedback. `pynxtools` is built mainly within FAIRmat Area B - Experiment.

You can reach us through different channels. You can send an email directly to one of the main contributors:

| Name | E-mail     | Github profiles |

Alternatively, you can also:

- Open an issue on [GitHub](https://github.com/FAIRmat-NFDI/pynxtools-xrm/issues)
- Join the [NOMAD discord channel](https://discord.gg/Gyzx3ukUw8) and ask us there directly.
